새롬동 교습소
사회 과목의 서술형 문제에서는 채점 기준 분석 연습을 충분히 해야 하며, 실제 출제 기준에 맞춰 ‘핵심 개념 포함 여부’, ‘사례 제시’, ‘정당화 논거’ 등을 따로 체크하는 연습을 반복하면 감점 요소를 사전에 차단할 수 있다. 복습 자료를 따로 만들기보다는 기존 학습 자료에 형광펜, 메모, 체크리스트 등을 직접 추가함으로써, 학생이 자신의 학습 이력을 시각적으로 추적할 수 있도록 돕는다. 새롬동 교습소은 이러한 작고 반복되는 행동은 마치 바이러스 백신처럼, 나중에 큰 지식 구조를 다룰 때 흔들리지 않도록 기반을 탄탄히 다지는 역할을 한다. 오답노트에는 단순한 정답 외에도 기억법이나 암기 팁을 따로 표시해둔다. 예를 들어, 과학 예상문제 요약본을 매주 한 번씩 정리하면서, 실제 기출문제와 비교하여 적중률을 점검하면 자신감과 예측력을 동시에 높일 수 있다. 예를 들어, 수학 문제를 등장인물 간의 대화극으로 만들고 등식의 양변 정리 과정을 각 캐릭터의 역할 분담처럼 표현하면 복잡한 조건도 친숙하게 다가오며, 이는 특히 직관이 부족한 학생에게 강력한 사고 도구가 된다.
